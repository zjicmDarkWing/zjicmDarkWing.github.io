ip-10-129-177 (makesense.htb) 完整 Writeup

0. 侦察

目标 10.129.177.220，开放端口：

  • 22/tcp OpenSSH 9.6p1 (Ubuntu)
  • 443/tcp Apache 2.4.58 ssl/http，TLS 证书 CN=makesense.htb
  • 80/tcp filtered

443 上是 WordPress 站点（标题 “Agency LLC”），使用自定义主题 webagency。将 makesense.htb 加入 hosts 后访问。

1. Stored XSS —— webagency 主题的 Whisper 语音管道

主题内置一条客户端 “语音/联系表单” 管道，前端 whisper-wrapper.js 中硬编码了加密密钥：

流程为两个 admin-ajax.php 动作：

  1. action=submit_contact_form（匿名 nonce 4c58dec735）→ 返回 post_id
  2. action=save_voice_results（post_id + encrypted_payload）

encrypted_payload 是对 JSON {transcription, summary} 的 AES-GCM 加密：key = SHA-256(ENCRYPTION_KEY)，12 字节 IV 前置，整体 base64。服务端解密后存储，供后台 admin 审核。前端 applySymbolMapping 会把内容拼成 HTML（如 <script>）——即存储型 XSS。由于密钥硬编码，可绕过录音直接伪造任意 HTML 载荷。
